# 巽風堪輿研究中心｜Cloudflare Pages + Formspree 正式上線版

## 頁面
- index.html：首頁
- about.html：關於巽風
- services.html：服務方案與價格
- enterprise.html：年度企業顧問
- cases.html：案例實績與照片輪播
- courses.html：課程講座
- booking.html：預約表單（Formspree）
- thanks.html：送出感謝頁
- privacy.html：隱私權說明
- 404.html：錯誤頁面

## 上線平台
建議使用 Cloudflare Pages Direct Upload。

詳見：CLOUDFLARE_FORMSPREE_SETUP.md
