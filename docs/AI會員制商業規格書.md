# 巽風 AI 會員制商業規格書

## 產品定位

「巽風 AI 會員系統」不是販售 ChatGPT 連結，而是把風羿老師的專業知識、諮詢流程、課程內容與場域判斷邏輯產品化，成為可持續收費的會員服務。

## 核心價值

1. 將風水、命理、掌訣、場域管理轉為可重複使用的 AI 諮詢入口。
2. 用會員制建立穩定現金流。
3. 用 AI 做前置判斷、收案整理、課程複習與預約導流。
4. 高價值個案仍導向風羿老師本人正式諮詢。

## MVP 收費邏輯

付款方式先不做全自動，採「人工收款 + 啟用碼開通」。

優點：

1. 最快上線。
2. 不必一開始卡在金流串接。
3. 可以先驗證市場願不願意付費。
4. 後續可無痛升級為綠界、藍新或 LINE Pay 自動開通。

## 會員級距

### 免費體驗

- NT$0
- 少量體驗
- 導流正式會員

### 月費會員

- NT$888 / 月
- 100 問
- 個人命理、風水初判、掌訣問答

### 進階會員

- NT$3,600 / 月
- 500 問
- 進階命理、陽宅初評、企業場域初判

### VIP 顧問會員

- NT$9,800 起 / 月
- AI 問答 + 風羿老師本人檢視

## 風控規則

1. AI 回答不得取代醫療、法律、投資專業判斷。
2. 正式風水判斷仍需由風羿老師本人親至現場評估。
3. AI 不宣稱通靈、真實讀取阿卡西紀錄。
4. 使用者資料不得公開。
5. API Key 與管理金鑰不得放在前端。

## 營運 SOP

1. 客戶看會員方案。
2. LINE 洽詢付款。
3. 後台產生啟用碼。
4. 客戶註冊會員。
5. 客戶輸入啟用碼。
6. 客戶進入 AI 會員版。
7. 使用次數扣點。
8. 次數用完或到期後續費。
